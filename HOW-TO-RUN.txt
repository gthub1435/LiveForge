LIVE LAYOUT EDITOR WEBSITE — NO LOGIN
===================================
1. Extract this ZIP.
2. Open index.html, or double-click START-WEBSITE.cmd on Windows.
3. The complete website runs locally. No login or package installation is needed.

To publish: upload this folder's contents to GitHub, import it in Vercel, select
Other, leave Build Command unset, and set Output Directory to .
Make the production deployment public and disable any hosting login protection.
Full details are in README.md.
